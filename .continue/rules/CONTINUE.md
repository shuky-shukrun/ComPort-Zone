# ComPort Zone Continue Rules

Use `AGENTS.md` as the primary project guide.

## Start Points

- Read `docs/LLM_CHANGE_GUIDE.md` before making code changes.
- Use `docs/ARCHITECTURE.md` for current subsystem ownership and refactor status.
- Use `docs/DESIGN.md` for deeper design, module maps, and data/control flows.
- Inspect the closest focused tests before editing.

## Commands

```powershell
.\setup_dev.bat
.\run_tests.bat
.\scripts\run_tests.ps1 tests.test_quick_actions
.\launch_app.bat
.\build_exe.bat
git diff --check
```

The test suite is `unittest`-based. Do not use pytest guidance for this repo unless the project explicitly migrates.

## Local Guardrails

- Avoid generated and local output paths such as `.venv`, `build`, `dist`, `release`, and `__pycache__`.
- Keep Qt widget dependencies out of pure domain/service modules.
- Preserve app settings JSON and quick action CSV compatibility unless explicitly changing those formats.
- Do not assume physical COM hardware exists in tests.
- Leave `.codex/environments/environment.toml` alone because it is autogenerated.
